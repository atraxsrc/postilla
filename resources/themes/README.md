# Cedilla syntax highlighting themes

Drop theme files into Cedilla's theme folder (open it from *Settings →
Appearance → Open themes folder*) or import them with the *Import theme*
button. Three formats are understood:

| Format | Extension | Notes |
| --- | --- | --- |
| Cedilla theme | `.ron` | Simple named colors, see `example-cedilla-theme.ron` |
| COSMIC Terminal color scheme | `.ron` | The same files COSMIC Terminal imports/exports, see `example-cosmic-term.ron` |
| TextMate / Sublime theme | `.tmTheme` | Any theme from the Sublime Text ecosystem |

The theme format is detected automatically.
